# RE:CALL — TOEFL Study Deck

브라우저에서 바로 사용하는 개인 TOEFL 반복 학습장입니다. 단어, 중요 문장, 오답을 저장하고 3단계 자기평가로 다음 복습 시점을 자동 조절합니다.

## 기능

- 단어 / 중요 문장 / 오답 카드 생성, 검색, 수정, 삭제
- 오늘 학습할 카드 자동 선정
- `MASTER` / `SOSO` / `NOT AT ALL` 3단계 평가
- SM-2 기반 간격 반복 및 실패 카드 세션 내 재출제
- 일일 학습량, 연속 학습일, 응답 통계
- 브라우저 로컬 저장 및 JSON 백업·복원
- 모바일·데스크톱 반응형 UI

## 반복 알고리즘

공개된 [SuperMemo SM-2](https://super-memory.com/english/ol/sm2.htm)를 3개 버튼에 맞게 적용했습니다.

| 버튼 | SM-2 점수 | 동작 |
|---|---:|---|
| MASTER | 5 | 기억 난이도 계수를 높이고 복습 간격을 늘림 |
| SOSO | 3 | 성공으로 처리하되 난이도 계수를 낮춰 더 자주 복습 |
| NOT AT ALL | 1 | 성공 횟수와 간격을 초기화하고, 오늘 세션 뒤쪽에 재출제 |

성공한 카드의 기본 간격은 1일, 6일, 이후 `이전 간격 × 카드별 ease factor`입니다. Ease factor의 최솟값은 1.3입니다.

## 실행

별도 설치 없이 `index.html`을 열면 됩니다. 로컬 서버를 쓰려면:

```bash
python3 -m http.server 8080
```

이후 `http://localhost:8080`에서 접속하세요.

개발 검증을 실행하려면:

```bash
npm install
npm test
```

## 데이터 안내

데이터는 서버가 아니라 현재 브라우저의 `localStorage`에 저장됩니다. 다른 기기와 자동 동기화되지 않으므로 **기록 · 설정 → JSON 내보내기**로 주기적으로 백업하세요.
